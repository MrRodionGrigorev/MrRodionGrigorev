## About me

I'm a software engineer focused on systems integration and business automation. I design and build backend services, internal tools, data pipelines, CRM and ERP workflows, API integrations, reporting systems, and applied AI solutions.

My work usually starts with a real operational problem: disconnected systems, repetitive manual work, unreliable data exchange, or processes hidden in spreadsheets. I turn those workflows into maintainable software using Python, APIs, databases, queues, automation tools, and practical AI where it adds value.

- Build backend services and REST APIs with Python, FastAPI, Django, and Flask
- Integrate CRM, ERP, email, spreadsheets, external APIs, and internal systems
- Design PostgreSQL data models, synchronization pipelines, parsers, and reporting workflows
- Automate document processing, data extraction, classification, and operational tasks with LLMs
- Work across architecture, implementation, testing, deployment, and stakeholder communication
- Based in Saint Petersburg, Russia; open to remote and international work

## Selected impact

- Reduced manual processing by up to **60%** through backend services and workflow automation
- Cut deployment time from **40 minutes to under 8 minutes** with Docker and CI/CD
- Increased background-job throughput by **3x** with Celery and Redis
- Reduced PostgreSQL query time by **40%** for reporting workloads
- Replaced recurring spreadsheet operations with internal dashboards and automated pipelines
